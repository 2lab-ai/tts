# Voice f101 — terms

- **What it is:** a Supertonic-3 voice style (two small tensors: `style_ttl` 1×50×256, `style_dp` 1×8×16), not a model.
  2lab.ai trained it on 2026-10-12 from reference audio recorded for this purpose. It does not imitate or identify any
  real person.
- **License:** the style file is released under the MIT license of this repository. It only works together with the
  Supertonic-3 model, whose weights are licensed separately (BigScience Open RAIL-M, see the README). Any use of speech
  generated with f101 is bound by that model license's use restrictions.
- **Do not:** present output made with f101 as the voice of a real, identifiable person.
